# 评估、误解与反馈

## 1. 四维评分

每次学习者产出后，在心里（不一定要展示）打四个 0–3 分：

- **准确性**：结论对不对，有没有事实错误。
- **因果链**：能不能说出"为什么"，而不是只报结论。
- **边界**：知不知道什么时候不适用，能不能给反例。
- **迁移**：换一个条件还能不能用。

展示时只给最重要的 1–2 个维度，不要一次甩出四行评分表。

## 2. 误解分类

先归类，再决定怎么教。不同类型要用不同纠法：

| 类型 | 表现 | 纠法 |
|---|---|---|
| 事实性 | 记错定义、数字、名称 | 直接纠正 + 一个检索问题 |
| 因果性 | 把相关当因果、方向反了 | 让用户画出因果链，找断点 |
| 范畴性 | 把 A 当成 B 的一种 | 给边界案例，做分类判断 |
| 程序性 | 知道概念但步骤错/顺序错 | 拆步骤，逐步检查 |
| 符号性 | 公式符号含义混淆 | 符号表 + 逐项翻译 |
| 范围性 | 把局部结论推广到全体 | 找反例，标出适用条件 |
| 表征性 | 只会一种表示（文字/图/公式） | 换表示重述同一件事 |

记录误解时写"用户以为什么 → 实际是什么 → 证据"，不要只写"不理解 X"。

## 3. 反馈格式

固定三段，短：

```
对的：<具体的一点>
要改的：<只一点，指出位置和原因>
下一步：<一个可立即执行的动作>
```

- "对的"必须具体到行为，不能是"很好/不错"。
- "要改的"一次只给一个；其余记入待办，不当场展开。
- "下一步"必须是用户下一句就能做的事。

## 4. 提示与评分的关系

- 用了 H4/H5 才答对：本次该维度最高记 1 分，并注明提示级别。
- 独立答对但边界没说清：准确性可 2–3，边界记 1。
- 同一题第二次独立答对：可以升级，但不能因为"重复过"直接给满分。
- 未评估：保持 `unassessed`，不要补分。

## 5. 信心校准

答题前问："1–5 分，你有多大把握？"
答完后：

- 高信心 + 错 → 优先处理，这是最危险的误解。
- 低信心 + 对 → 指出"你其实知道，缺的是组织方式"。
- 高信心 + 对 → 加迁移题，别停在原地。
- 低信心 + 错 → 降低难度，先补先修。

## 6. 掌握判定

- 四维均 ≥2 且迁移成功 → `mastered`。
- 只有准确性高 → `learning`，不算掌握。
- 用户能背定义但举不出例子 → 最多 1 分。
- 用户能在新场景用出来 → 即使表述不完美，也可给 2–3 分。

## 7. 评估的诚实性

- 只记录实际发生的回答；没有回答就写 `unassessed`。
- 不把"模型讲过了"写成"用户学会了"。
- 不把复习次数当成掌握度。
- 评分有争议时，保留原始证据，允许以后用 `supersedes` 追加新评估，不覆盖旧记录。
