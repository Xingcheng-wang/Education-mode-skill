# 脑科学/认知科学：用机制，不用神话

## 1. 可用机制

| 机制 | 设计动作 | 说明 |
|---|---|---|
| 预测误差 | 先让用户猜，再揭示；对比差异 | 大脑对“意外”更敏感，错误是信息 |
| 检索练习 | 先回忆，再重读；想不起来再提示 | 提取比重复阅读更能巩固 |
| 间隔重复 | 把练习摊到多天，而不是一次刷完 | 遗忘曲线与巩固需要时间 |
| 交错练习 | 混合相近但不同的题型 | 训练辨别，而不是套模板 |
| 认知负荷 | 一次一个点；分块；先示例后独立 | 工作记忆容量有限 |
| 双重编码 | 文字 + 图/表/手势/代码 | 多通道表征，降低抽象难度 |
| 具身/行动 | 做、画、搭、演示、改一个参数 | 行动参与能加深理解 |
| 睡眠与巩固 | 建议跨天复习，不鼓励通宵 | 睡眠参与记忆巩固 |
| 压力与情绪 | 安全、幽默、自主；中等挑战 | 威胁会窄化注意，安全促进探索 |
| 注意 | 短时专注 + 休息；不 multitask | 注意力是稀缺资源 |

## 2. 明确排除的 neuromyth

- 学习风格（视觉型/听觉型/动觉型）；
- 左右脑分工决定学习方式；
- “人只用了 10% 的大脑”；
- 睡眠学习（sleep-learning）；
- 通用“大脑训练”能大幅迁移到其他能力；
- 把“多巴胺”当万能解释；
- “数字原住民”天然擅长技术；
- 莫扎特效应能提高智力。

## 3. 使用原则

- 脑科学是**约束和机制**，不是营销话术。
- 不声称“脑科学证明应该这样”；说“这与认知科学的研究方向一致”。
- 证据强度不同：检索、间隔、交错、认知负荷较稳；具身、情绪、睡眠的机制更复杂，别过度承诺。
- 个体差异很大；用户的实际反应优先于任何理论。
- 如果某个机制让用户更焦虑、更困惑，停用它。

## 4. 与模式的结合

- `curiosity`：先预测/观察，再解释；用一个具体现象做锚点。
- `systematic`：每个节点至少一个“做”的任务；跨天重访。
- `skill-drill`：短回合、即时反馈、撤脚手架、交错练习。
- `deep-read`：先预测作者会怎么做，再读；读后用自己的话重建论证。
- `spark`：最小验证就是实践；先做小实验，再决定是否投入。
