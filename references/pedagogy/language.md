# 语言：术语首现解释与全局术语表

## 1. 硬规则

任何**缩写、英文简写、专业词**第一次出现时，给：

1. 全称；
2. 一句话白话解释；
3. 一个例子；
4. 之后再用简称。

格式：

```
中文（English, ABBR）——一句白话解释。例：……
```

示例：

- LLM（Large Language Model，大语言模型）——一种用大量文本训练、能生成语言的模型。例：用 LLM 解释概念。
- FPGA（Field-Programmable Gate Array，现场可编程门阵列）——一种出厂后还能重新配置电路的芯片。例：用 FPGA 做流水灯。
- ZPD（Zone of Proximal Development，最近发展区）——跳一跳够得着的那段难度区间。例：在 ZPD 内练习。
- SM-2（SuperMemo 2，一种间隔重复算法）——根据回忆情况安排下次复习时间的算法。例：用 SM-2 安排重访。
- provenance（来源追溯）——记录一条信息从哪里来、经过谁、是否被修改。例：记忆迁移时保留 provenance。

## 2. 全局术语表

- 文件：`<EDU_HOME>/learner/glossary.md`
- 每次会话开始先读；遇到新术语，首现解释后追加一行。
- 字段：`term | full form | plain meaning | example | first seen`
- 同一术语不重复解释；如果用户已经正确使用，可以只轻轻确认一次。

## 3. 避免缩写汤

- 能白话就不缩写。
- 一个句子里最多一个缩写；如果需要三个，先拆句。
- 不为了显得专业而使用术语；术语是为了减少歧义，不是为了增加门槛。
- 用户用了某个术语但可能不确定时，先用一句话确认：“你说的 X 是指……吗？”

## 4. 解释的粒度

- 一句话白话 + 一个例子，通常够了。
- 不要贴词典定义；不要一次讲三个义项。
- 如果术语背后有重要机制，先给最小解释，等用户需要时再展开。
- 中文里夹英文时，第一次给中文（English, ABBR），之后可以只用中文或简称。

## 5. 什么时候可以省略

- 用户在本次会话已经定义过；
- 术语是用户先提出的，且用法正确；
- 极其常见的词（如 API、CPU）也要看用户背景；不确定就给半句解释。

原则：**宁可多解释半句，不要让用户因为一个缩写掉队。**
