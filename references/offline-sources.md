# 离线资料接入与引用

## 1. 支持格式

| 格式 | 依赖 | 说明 |
|---|---|---|
| `.txt` / `.md` | 无 | 最稳，推荐 |
| `.epub` | 无（stdlib） | 按章节解析 XHTML |
| `.pdf` | `pdftotext`（poppler）或 `pypdf` | 无依赖时请先转 txt |
| 扫描版 PDF | OCR 工具（本 skill 不内置） | 先离线 OCR 成 txt |

不支持的格式不要猜内容；请用户转换后再 ingest。

## 2. 接入流程

```bash
# 1. 放入 inbox（也可以直接指定任意本地路径）
cp book.pdf <EDU_HOME>/corpus/inbox/

# 2. 建立索引
python <SKILL_DIR>/scripts/edu.py ingest --home <EDU_HOME> --file <EDU_HOME>/corpus/inbox/book.pdf --id book-x

# 3. 检索
python <SKILL_DIR>/scripts/edu.py search --home <EDU_HOME> --query "关键概念" --source book-x --top 5
```

- `ingest` 会生成 `meta.json`、`chunks.jsonl`、`text.txt`。
- 同一 `id` 重复 ingest 会覆盖该来源的索引，不影响其他来源。
- 原始文件保留在 `inbox/`，不自动删除。

## 3. 分块与定位

- 默认块大小约 900 字符，重叠 120 字符。
- PDF 按页定位：`p.12`。
- EPUB 按章节文件定位：`chapter03.xhtml`。
- TXT/MD 按行号定位：`lines 120-168`。
- 引用时使用 ingest 输出的 locator，不要自己估算页码。

## 4. 引用规范

| 标注 | 含义 | 示例 |
|---|---|---|
| `[S:id p.7]` | 本地资料原文/转述 | `[S:paper-x p.7]` |
| `[M]` | 模型自身知识 | `[M]` |
| `[?]` | 不确定，需核实 | `[?]` |

规则：

1. 每个事实性陈述至少带一个标注。
2. 直接引用加引号，且不超过 120 字。
3. 转述也要标来源；不要因为改了措辞就当成自己的知识。
4. 找不到就说"本地资料没有"，不要用 `[M]` 冒充 `[S:]`。
5. 不引用未 ingest 的文件，除非用户当场贴出原文。

## 5. 隐私与安全

- 所有索引、状态、日志都在 `<EDU_HOME>` 内，不上传。
- `search` 是本地关键词检索（BM25），不使用云端 embedding。
- 不读取 `corpus/` 之外的文件，除非用户明确指定。
- 会话记录可能包含用户原话；共享机器上建议设置目录权限。
- 删除资料：删除对应 `corpus/<id>/` 即可；会话中的引用不会自动清除。

## 6. 资料质量

- 优先一手资料：论文原文、教材、官方文档。
- 二手解读只作为补充，引用时注明。
- 多来源冲突时，并列呈现，不擅自裁决；标注各自年份和立场。
- 资料过期时提示用户，不要假设仍然成立。

## 7. 无资料时

- 明确说："本地没有可引用的资料，以下基于模型知识 `[M]`。"
- 对高风险内容（医学、法律、安全操作）降低确定性，建议用户核对一手资料。
- 不因为"离线"就降低来源标注要求。
