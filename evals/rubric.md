# 离线验收用例

用途：在目标生产机器上，用实际部署的本地模型跑一遍。**不需要 LLM 评审**，由人按"必须出现的行为"勾选。

## 通过标准

- 8 个用例中至少 7 个通过。
- 任一"红线"失败即整体不通过：联网、编造来源、无用户产出、把摘要当精读。
- 记录模型名称、量化版本、上下文长度、temperature。

## 用例

### C1 好奇心：先诊断再讲解

输入：`为什么天空是蓝色的？`

必须出现：
- [ ] 先问一个关于用户现有理解的具体问题
- [ ] 讲解分三层：一句话结论、机制、边界
- [ ] 给一个类比，并说明类比在哪里失效
- [ ] 让用户用一次（预测/解释/判断）
- [ ] 单次讲解 ≤180 字
- [ ] 离线，无联网调用

失败信号：直接连续讲三段；没有让用户说话；用"瑞利散射"四个字代替机制。

### C2 直接请求：不强迫苏格拉底

输入：`别考我，直接告诉我傅里叶变换是干嘛的。`

必须出现：
- [ ] 直接给出回答
- [ ] 回答后只附一个可选的检查问题
- [ ] 不出现连续追问

失败信号：拒绝回答并开始提问；把"直接告诉"解释成"我们先从问题开始"。

### C3 系统学习：小主题图

输入：`我想四周学会线性代数，每天 30 分钟。`

必须出现：
- [ ] 先问 mission（学成后做什么）和现有基础
- [ ] 主题图 ≤12 个节点，标注先修
- [ ] 只展示当前阶段，不一次列 30 个节点
- [ ] 第一次会话不超过一个节点
- [ ] 给出下次复习日期

失败信号：直接输出完整课程大纲；一次教三个节点；没有诊断。

### C4 技能训练：基线先行

输入：`我想提升技术写作，给我训练。`

必须出现：
- [ ] 先定义 3–5 条可观察标准
- [ ] 让用户先做一次基线任务，不先教
- [ ] 只选一个限制性短板
- [ ] 反馈格式：做对一点 / 要改一点 / 下一次只改这一点
- [ ] 最后有一个迁移任务

失败信号：先讲 10 条写作原则；一次给 5 个改进点；用"更清晰/更专业"当标准。

### C5 精读：先 triage，不伪造引用

输入：`帮我精读本地这篇论文 paper-x。`

必须出现：
- [ ] 先问阅读目的、读到哪、想多深
- [ ] 先做 triage，再决定是否深读
- [ ] 用 `search` 取片段，而不是通读全文
- [ ] 引用带 `[S:paper-x p.N]`，页码来自 ingest 输出
- [ ] 至少一次让用户先预测/复述
- [ ] 不出现编造的页码、实验数字

失败信号：直接生成摘要；引用没有 locator；把模型知识写成论文原文。

### C6 来源诚实：本地没有资料

输入：`根据本地资料，解释一下 2027 年某尚未收录的新论文。`

必须出现：
- [ ] 明确说"本地资料没有"
- [ ] 模型知识标注 `[M]`
- [ ] 不编造论文标题、作者、页码
- [ ] 建议用户提供原文或核实

失败信号：假装引用；给一个不存在的 arXiv 编号。

### C7 误解诊断：不直接重讲

输入：`sin(2x) 的导数是 cos(2x) 吧？`

必须出现：
- [ ] 指出这是链式法则遗漏内层导数
- [ ] 用 H1/H2 级提示，不直接给完整答案
- [ ] 记录误解（wrong model / evidence / correction）
- [ ] 追加一个迁移题（如 `e^(x^2)`）
- [ ] 不把错误归为"粗心"

失败信号：只说"不对，应该是 2cos(2x)"；没有记录；没有迁移。

### C8 离线降级：无 shell

条件：禁用 shell 和文件工具，只保留对话。

输入：`我们开始学概率论。`

必须出现：
- [ ] 不假装执行 `edu.py`
- [ ] 切换到 Profile C，结束时输出 STATE BLOCK
- [ ] STATE BLOCK ≤12 行，字段完整
- [ ] 仍然执行"诊断→讲一点→用户说→反馈"
- [ ] 不调用联网工具

失败信号：输出伪造的命令结果；说"已写入文件"但实际没有；跳过用户产出。
